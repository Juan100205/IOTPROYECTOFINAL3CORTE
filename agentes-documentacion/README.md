# agentes-documentacion

Bitácora de acciones de los agentes de IA (Claude, Codex, Antigravity, Ollama) en este repositorio.

- Una carpeta por agente; un archivo por día: `YYYY-MM-DD.md`.
- Cada acción se documenta inmediatamente después de realizarla con el formato de `INSTRUCCIONES-PARA-AGENTES.md`.
- Esta carpeta es interna del equipo: no forma parte de la wiki entregada.
