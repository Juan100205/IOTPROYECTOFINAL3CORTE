## Anexo B. API REST del tablero

Todas las rutas pasan por `filtroRed()`. Las marcadas con 🔒 exigen además una sesión válida.

| Método | Ruta | Descripción | Respuesta |
|---|---|---|---|
| GET | `/login` | Formulario de ingreso | HTML |
| POST | `/login` | `usuario`, `clave` | 302 a `/` con cookie, o a `/login?e=1` (clave errada) o `?e=2` (IP bloqueada) |
| POST | `/logout` | Cierra la sesión | `{"ok":true}` |
| GET 🔒 | `/` | Tablero | HTML autocontenido con `<canvas>` |
| GET 🔒 | `/api/estado` | Estado, IRH, evaporación, DPV, descenso, reglas, sensores, valores y eventos | JSON |
| GET 🔒 | `/api/historial` | 180 muestras (paso de 5 s) de nivel, tAgua, tAmb, hum, pres, lum, evap, irh y colAgua | JSON |
| POST 🔒 | `/api/alarma` | `accion=silenciar` o `accion=rearmar` | `{"sil":true/false}` |

## Anexo C. Formato del log CSV (v8)

| Columna | Unidad | Descripción |
|---|---|---|
| `LOG` | — | Marcador para filtrar las líneas |
| `millis` | ms | Tiempo desde el arranque |
| `nivel`, `nivelUS`, `nivelP` | % | Nivel fusionado, por ultrasonido y por presión |
| `tAgua`, `tAmb` | °C | Temperatura del agua y del aire |
| `humedad` | % | Humedad relativa |
| `presion` | hPa | Presión atmosférica |
| `luminosidad` | % | Lectura relativa de la LDR |
| `evap` | 0-100 | Índice de evaporación |
| `dpv` | kPa | Déficit de presión de vapor |
| `descenso` | %/min | Tasa de descenso (positivo = baja) |
| `irh` | 0-100 | Índice de Riesgo Hídrico |
| `anomalias` | 0-4 | Contador de anomalías |
| `estado` | 0-4 | 0 NORMAL, 1 ALERTA, 2 CRITICO, 3 DEGRADADO, 4 ERROR |

## Anexo D. Calibración del MD-PS002

1. Encender con la manguera fuera del agua (tara automática).
2. Anotar `HX crudo` en el aire y con la punta sumergida a una profundidad conocida *H* (cm).
3. Calcular `HX_CUENTAS_POR_KPA = (crudo_sumergido − crudo_aire) / (H × 0,0980665)` y cargar el valor en el firmware.
